# Portafolio – Análisis y Predicción del PIB

## Objetivo del proyecto

El objetivo de este proyecto es crear un método de agrupamiento para ordenar paises en diferentes niveles de progreso económico, usando información variada del Banco Mundial. Esta asignación busca juntar países basándose en parecidos fundamentales en aspectos sociales, financieros y ecológicos, y no solo mirando su ingreso individual, ofreciendo así una perspectiva más completa y profunda sobre el desarrollo.

El enfoque pretende elaborar instrumentos aprovechables para quienes diseñan políticas, organizaciones no gubernamentales o investigadores del progreso sostenible, al simplificar el hallazgo de tendencias compartidas entre paises con desafios o ventajas parecidas. También, se examina de qué forma la simplificación de variables usando PCA influye tanto en la capacidad de predicción como en lo fácil que es entender el modelo.

A diferencia de una simple comparacion de tecnicas de métodos de aprendizaje automático, esta iniciativa se concibe como una imitación fiel de exploración y pronóstico dentro del ámbito del avance mundial, incluyendo justificaciones para las elecciones analíticas tomadas en cada paso. Por ende, el trabajo no solo persigue el mejor resultado algorítmico, sino también producir saberes prácticos y replicables desde una perspectiva crítica y funcional.

## Organización del trabajo
El proyecto se desarrolla de manera progresiva en tres etapas:
- **Etapa 1:** Exploración y análisis descriptivo de los datos.
- **Etapa 2:** Aplicación de técnicas de reducción de dimensionalidad.
- **Etapa 3:** Construcción y evaluación de modelos de clasificación.
