# Portafolio – Análisis y Predicción del PIB

## Objetivo del proyecto
Este proyecto busca examinar datos del Banco Mundial con el propósito de calcular la riqueza nacional de varias países, basándose en factores económicos, sociales y de población.

## Finalidad
El trabajo del esfuerzo es implementar diversas estrategias de análisis de datos, abarcando desde la descripción inicial y el manejo de información ausente hasta técnicas para simplificar la complejidad y modelos para agrupar, todo esto incorporando métodos adecuados de seguimiento de cambios a través de GitHub.

## Organización del trabajo
El proyecto se desarrolla de manera progresiva en tres etapas:
- **Etapa 1:** Exploración y análisis descriptivo de los datos.
- **Etapa 2:** Aplicación de técnicas de reducción de dimensionalidad.
- **Etapa 3:** Construcción y evaluación de modelos de clasificación.
